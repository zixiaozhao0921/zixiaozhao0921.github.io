# Zixiao Zhao · Academic homepage

This repository serves the personal website at <https://zixiaozhao0921.github.io/> through GitHub Pages.

Edit `index.html` for the profile, research, preprint, contact information and honors. The homepage uses `static/css/main.css` and the portrait in `static/assets/img/photo.png`. The earlier Markdown homepage materials remain in `contents/`.

Open `index.html` in a browser to preview changes locally. To publish reviewed edits, commit them to the site's publishing branch and push to GitHub. The page requires no build step.

The original site used [Sen Li's academic homepage template](https://github.com/senli1073/senli1073.github.io). See LICENSE.
